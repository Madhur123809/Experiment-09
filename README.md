Theory:

NumPy (Numerical Python) is a powerful open-source library used in Python for numerical and mathematical computations. 
It provides support for large, multi-dimensional arrays and matrices along with a collection of mathematical functions 
to operate on these data structures efficiently.

The core object of NumPy is the ndarray (N-dimensional array). Unlike Python lists, NumPy arrays store elements of the
same data type and are more memory-efficient and faster for numerical operations. NumPy arrays allow vectorized 
operations, meaning mathematical computations can be performed on entire arrays without using explicit loops, which
improves performance.


NumPy provides various functionalities such as:

A ->  Array Creation: Arrays can be created using functions like array(), zeros(), ones(), arange(), and linspace().

B ->  Array Operations: Arithmetic operations (addition, subtraction, multiplication, division) can be performed
element-wise between arrays.

C ->  Indexing and Slicing: Elements or subsets of arrays can be accessed and modified using indexing and slicing techniques.

D ->  Shape Manipulation: Functions like reshape(), flatten(), and transpose() help in changing the structure of arrays.

F  ->   Mathematical Functions: NumPy provides built-in mathematical operations such as mean, sum, standard deviation, square 
root, and trigonometric functions.

G  ->  Multi-Dimensional Arrays: It supports 1D, 2D, and higher-dimensional arrays, which are widely used in data analysis, 
machine learning, and scientific computing.

Commands Used :

1 -> a.ndim : Tells us about the dimensions of matrix/array

2 -> a.size : Tells us about the size of matrix/array

3 -> a.shape : Tells us about the shape of matrix/array

4 -> a.dtype : Tells us about the datatype of matrix/array

5 -> np.zeros : makes a null matrix

6 -> np.ones : makes an matrix of 1's

7 -> np.eye : makes an identity matrix

8 -> np.arange : used to create an array of evenly spaced values within a given range.

9 -> np.linspace : creates an array of evenly spaced numbers between two specified values.

10 -> np.mean : mean of matrix

11 -> np.median : median of matrix

12 -> np.min : displays the minimum value of a matrix

13 -> np.max : displays the maximum value of a matrix

14 -> np.sum : Displays sum of matrix
